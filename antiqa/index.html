How it works

Three steps. No new account.

01

Add a pack

Everything product-specific lives in a pack: a manifest, a study, user stories, plays and a harness that starts the app. The core never names a product.

02

Play the stories

A Playwright runner plays each story in a real browser, crawls the app and runs accessibility checks. Every miss gets a video.

03

Get a report an agent can fix

Every failure is triaged, then written to BUG-REPORT.md with an evidence.zip. Exit codes tell your pipeline what happened.
